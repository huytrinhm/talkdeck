## Actionable wiring checklist

1. **Hosting:** deploy the frozen client to the existing Site with the exact approved secret/R2/cookie configuration; verify anonymous visitor isolation and actual capabilities. Pairing metadata10min, rate-limit metadata≤1h, sealed key cookie1h; no audio/transcript storage or external relay. Keep real-key/provider/device tests separately authorized.
2. **Orchestration owner:** expose an authenticated session/gateway and bind visitor credentials server-side. Use stable slide IDs and serial mono24kHz PCM16 chunks with session-wide `X-Audio-Sequence`/`X-Slide-ID`, followed by audio/commit; direct full-text `{text,revision,slideId}` is an exclusive alternative. Buffer audio across navigation; old segments stay with original IDs. Replay SSE with Last-Event-ID and handle close/expiry/error.
3. **Orchestration + generation owners:** replace unconditional legacy Publisher with injected canonical JSX backend; bind immutable source contexts/unified tools, durably retain utterances before inference, carry pause/history cancellation epochs and subscribe accepted commits. Do not create a second authority over the same deck.
4. **Frontend + generation owner:** use `GenerationSession`, backend-supplied viewer srcdoc and `mountViewer`. Generate unpredictable channel; exactly `sandbox="allow-scripts"`; validate iframe source/opaque origin/channel; wait ready; forward version1 sequence/publicationId/revision/slideId/html/css/readiness/motion/build/holdIds. Forward real applied/painted/settled/refused acknowledgments with measured clock offset/uncertainty. Block presentation if exact revision readiness fails; resynchronize after reconnect. Keep notes/source/transcripts private.
5. **All owners + QA:** map Add/select/next/pause/push-to-edit/Undo to the service semantics, preserve project/deck IDs and cancellation barriers, connect raw stream processing, and verify late events/reconnect/history/visitor isolation. Then run separately authorized real-phone/network/provider checks. Coach/Deep Refine/pet and broader network reachability are subsequent integrations, not release claims.

Blocking end-to-end: reachable authenticated generation session/key bridge, actor→JSX injection, canonical viewer bridge and raw-stream speech processor. Nonblocking for starting wiring: initial same-network scope, chunk warning, deferred optional companion/refinement UI and broader mobile/provider qualification.
