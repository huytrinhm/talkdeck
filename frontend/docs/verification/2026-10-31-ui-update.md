# Frontend UI update — 2026-10-31

Changes are confined to frontend. Projects are flat, the root panel is centered at a 1200px maximum, and creation ends with a bottom action. Stock neutral dark shadcn styles apply throughout the application. The editor sidebar stays visible, settings/toggle buttons are removed, and the filmstrip has a distinct surface and border.

Voice modes (Talk, Practice, Present) request listening on entry and reload; browser permission remains required. Pause, mute, visibility cleanup, and stale callback protection remain. The audience target uses the dark secondary button. Practice and Present display only the current session transcript; saved history is no longer rendered there. Stored project transcripts are preserved. System prompt is editable in Context. Completion returns to the selected slide.
