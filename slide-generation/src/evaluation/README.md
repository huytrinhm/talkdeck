# Evaluation evidence

This package supplies the P10 recording, paced driver, replay and comparison foundations. It does not supply an imitation of the adjacent orchestration scheduler. The five timed talks have not been qualified end to end. A live adapter must export `createEvaluationHost({ recorder, clock, initialContext, budget })`, connect the actual orchestration, mandatory checks and viewer, and attest a fresh session. It returns `EvaluationHost` plus `integration`, `finish()` statistics and `close()`; see `cli.ts`. Fixture expectations are evaluator-only and are never sent through this port. Model credentials come from the environment; source `.env` in the shell, never in code. The CLI rejects known environment credential values from artifacts.

Commands are `npm run eval:talks -- ...`, `eval:replay`, `eval:compare`, `eval:report` and `eval:freeze`; each supports `--help`. Output directories must be new paths below `.artifacts/`. Live runs require an explicit host module, fixture, manifest and budget. Missing audits become censored manual-review observations. Unknown costs or token counts remain null. Unknown host integrations are refused.

`driver.ts` schedules every input against its absolute monotonic deadline independently of model/retention promises, preserves the last event's silence, then permits bounded drain. Async recorder callbacks are observed without serializing delivery; errors and unfinished writes make recording incomplete. Hosts must return durable receipts in the same clock domain and honor abort. A Promise timeout cannot terminate an uncooperative host process; production adapters still need worker/process lifecycle control.

`RunRecorder` records exact request/response strings, raw tool arguments/results, input, events, normalized source/check/render state, viewer acknowledgments and separately identified frames. The host adapter is responsible for wiring every inference/tool/state/frame to it. Credentials and request headers are forbidden. Artifact manifests and files are exclusive; existing evidence is never rewritten. Viewer clocks require explicit offset and uncertainty. Evaluator screenshots are not model feedback.

Transaction replay initializes the exact recorded source, runs the actual engine and Chromium checks, verifies outcomes and exact source hashes, and maps fresh snapshot handles only after every recorded scope/revision/line/hash matches. Actor replay requires `createReplayHost` from the actual scheduler; its injected `RecordedResponses` returns literal responses after their recorded delays and rejects changed request context. `RecordedTools` verifies actual tool results before returning the recorded result. Only verified source-read handles and top-level edit transaction UUIDs are remapped bijectively; revisions, versions, findings and source remain exact. No live fallback exists. Default CLI replay blocks Node fetch/HTTP/TCP and the browser checker aborts page requests. This is application-level isolation, not an OS network namespace.

Freeze requires a clean committed source and creates a hashed immutable git archive/export without changing branches. Compare verifies that export, clean distinct candidate commits, fixture/model/dependency conditions, matched repetitions and exact observation/success identities. Offline timings never establish live latency gains. Even a complete fifteen-run measurement set leaves `qualificationComplete: false`: faithfulness, obsolete-value timelines, visual correctness, design and actual-host integration require review. Null/missed/censored observations stay in denominators; a faster successful subset is not a speed improvement.

Tests use explicitly synthetic cassettes except for the separately recorded subsystem smoke. `test/evaluation-replay.integration.test.ts` executes accepted/refused transactions and accepted actor-tool sequences through the real durable engine and Chromium. Real-model transaction replay evidence is at `.artifacts/recorded-model-offline-replay-20261031`; it exactly reproduces the six-call subsystem smoke's final source and passes readiness. This is not a five-talk run or orchestration qualification. See `docs/rounds/subsystem-smoke-2026-10-31.md` for evidence and limitations.
