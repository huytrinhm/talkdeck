Use a simple table when exact lookup or several comparable fields matter. Put concise column labels above clearly aligned rows; align numbers consistently and include units. Separate rows lightly or use restrained alternating tone. Emphasize only a meaningful supplied row, column or value. Keep the title and any interpretation outside the table. Do not turn each cell into a card, remove inconvenient fields or squeeze a large spreadsheet into one slide.

There is no Table primitive. For a small table, align labeled native text in consistent Row/Stack groups; preserve every value and unit. Use an existing validated definition when available. Do not invent HTML table tags.
